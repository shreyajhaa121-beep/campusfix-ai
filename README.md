# CampusFix AI 🏫

CampusFix AI is a smart campus and hostel complaint management system designed to help students report issues and track their resolution.

## 🚀 Features

- 📝 Report campus and hostel complaints
- 🆔 Automatic complaint ID generation
- 🎯 Automatic priority detection
- 👤 Automatic authority assignment
- 📊 Complaint dashboard statistics
- 🔍 Search and filter complaints
- 📋 Detailed complaint tracking
- 🔄 Complaint status management
- 📜 Complaint journey and history
- ⏳ 7-day resolution deadline tracking
- ⚠️ Automatic complaint escalation
- 🏢 Authority dashboard
- 💾 Local storage data persistence
- 📱 Mobile responsive design

## 🏗️ Complaint Flow

### Hostel Complaint

Student → Hostel Warden → College Main Authority

If a hostel complaint is not resolved within 7 days, it is escalated to the College Main Authority.

### College Complaint

Student → College Safety Department → College Main Authority

If a college complaint is not resolved within 7 days, it is escalated to the College Main Authority.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub Pages

## 📱 How to Use

1. Open CampusFix AI.
2. Report a campus or hostel issue.
3. The system automatically assigns the appropriate authority.
4. The system calculates priority based on the complaint.
5. Track complaint status and resolution progress.
6. If unresolved within 7 days, the complaint is escalated.

## 🎯 Project Purpose

CampusFix AI aims to improve communication between students and campus authorities by providing a centralized platform for reporting, tracking, and managing campus issues.
